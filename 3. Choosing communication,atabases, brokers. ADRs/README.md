За основу беру готовый вариант с контекстами и субдоменами
![bounded-contexts](./src/Context_mapping.png)
![subdomains](./src/subdomains.png)

Основные хар-ки, из требований:

| Subdomain | Bounded Context | Characteristics | Description |
|------------|----------------|-----------------|-------------|
| Привлечение клиентов | Кража аккаунтов из НСВ | Lead generation, acquisition | Получение клиентской базы через внешние источники и каналы привлечения. |
| Подбор лучшего (Г) персонала под задачу | Интеллектуальный матчинг сотрудников (для садженшенов) | Matching, recommendation engine, workforce allocation | Подбор наиболее подходящего сотрудника под задачу или заказ. |
| Выполнение поручений / заказов | Управление исполнением заказов | Order execution, operations | Непосредственное выполнение клиентских поручений и заказов силами персонала. |
| Решение проблем клиентов | Планирование визитов | Core domain, scheduling, orchestration | Планирование визитов сотрудников к клиентам, координация работ и ресурсов. |
| Решение проблем клиентов | Контроль качества работы сотрудников | Quality management, monitoring | Оценка и контроль качества выполнения работ сотрудниками. |
| Решение проблем клиентов | Расчет и списание средств у клиентов | Billing, payments | Расчет стоимости услуг и списание денежных средств с клиентов. |
| Решение проблем клиентов | Расчет и выплата зарплат сотрудникам | Payroll, compensation | Расчет вознаграждений и выплата заработной платы сотрудникам. |
| Поиск лучшего персонала на рынке (привлечение) | Хранилище проверки работников перед добавлением в систему (условно HRMS) | Recruitment, HR, compliance | Проверка кандидатов и хранение данных о сотрудниках до их допуска к работе. |
| Улучшение скорости обслуживания | Сборка необходимых расходников для заказа | Inventory preparation, fulfillment | Подготовка материалов и расходников перед выполнением заказа. |
| Увеличение лояльности клиентов | Производство Fortune-печенья | Customer engagement, loyalty | Дополнительная активность для повышения удовлетворенности и удержания клиентов. |
| Увеличение мотивации менеджеров | Тотализатор (ставки менеджмента happy cat box) | Gamification, incentives | Игровой механизм мотивации и вовлечения менеджеров. |
